## ⚠️ Loc 占比判据重议（手册 §6 “不符时”分支，待决策）

预注册判据“Loc 占比 > 47.1%”三种子均值 44.5% 未达（仅 seed0 单独达标），按纪律不能静默放行。
重议时供参考的事实：
1. Miss 预测完全兑现（34.8% → 0.3%），混合口径的 miss 主要来自退化图这一判断正确；
2. 绝对量纲：所有误差类型同步缩水（总可恢复 dAP 44.63 → 10.24），Loc 仍是**最大单项**
   （4.11 vs Cls 3.08 / Bkg 1.87），但 Loc:Cls 比从混合口径的约 10:1 降到约 1.3:1；
3. 定位受限的其余证据未削弱：AP50−AP75 在 ODC 口径**扩大**（28.83 > 27.64）；
   FalsePos ≫ FalseNeg；漏检几乎不存在；
4. seed 间 Loc 占比波动约 3 点（48.4/42.7/42.2），与 47.1 的差距在种子波动范围内，
   且 ODC 子集仅 1352 实例，占比估计本身偏噪。
待决策：按 (a) 如实报告 44.5% 并把“定位受限”的证据组合修订为
   “Loc 最大单项 + AP50−AP75 扩大 + FP≫FN + Miss≈0”，还是 (b) 先排查混合口径 47.1% 的
   复算口径（是否含 Dup、TIDE 版本、maxDets）后再定。**在决策前不开创新点 1。**

**决策（2026-09-05）：选 (b)** —— 用当前管线（同一 checkpoint / tidecv 1.0.1 /
默认参数 pos_threshold=0.5, background_threshold=0.1, max_dets=100 / 不含 Dup 的占比池）
重算混合口径 TIDE，检验能否复现历史值（loc 21.02 / miss 15.53 / both 4.75 / cls 2.11 /
bkg 1.22，占比 47.1%）：
- 复现 → 两口径可比，再判断 −2.6 的下降是否超出种子间波动；
- 不复现 → 47.1% 锚点不可比，改用重算的混合口径值作同口径新锚点，再与 ODC 的 44.5% 对比。

**执行结果（2026-09-05）：不复现，47.1% 锚点不可比。** 同 checkpoint/同数据/同 tidecv 1.0.1

来自不同模型状态/版本，**不可比**。
