## 事件记录：A1 fp16 溢出崩溃（2026-09-06）

现象   : epoch 11 iter 1，前向 pred_boxes 全 NaN → matcher giou assert 崩溃
尸检   : tools/analysis/nan_autopsy.py --snapshot ./NaN.pth
       → 可训练权重全干净；仅 encoder 的 108 个 BN running stats 全 NaN
       → decoder.anchors 的 Inf 为设计值（torch.where 的合法填充），非污染
根因   : 前向 fp16 激活溢出（encoder 第一个 lateral conv，3×3×1024 通道求和
       超过 fp16 上限 65504），BN batch stats=Inf → running stats 永久污染。
       **非 Haar 模块缺陷**：backbone 内部全有限、可训练权重全干净、前 10 epoch 健康
处置   : det_engine autocast 增加 AMP_BF16=1 环境开关（默认仍 fp16，其它实验零影响），
       A1 用 bf16 从 last.pth resume（重放 epoch 11，同 seed 可交叉验证崩点）
混杂声明: A1(bf16) vs baseline/A0r(fp16) 存在训练精度差异；文献量级 ≪ 配对
       门槛 1.9 AP。**预注册条件：若 A1 的最终配对 ΔAP 落在 ±1.9 内（边缘），
       则补跑 baseline-bf16 对照后再下结论；若差异显著则混杂不影响判定。**
